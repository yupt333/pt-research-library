# PT Research Library

PT Research Libraryは、理学療法研究で扱う文献情報をローカルに保存・検索・再利用するための個人用CLIです。肩関節、超音波、AHD、棘上筋、speckle tracking、reliabilityなどの文献を、大学院研究、学会発表、note記事、文献ライブラリ作成に活用する用途を想定しています。

## Phase 1でできること

- 文献の登録、一覧表示、詳細表示、編集、安全な削除
- キーワード検索と出版年・タグ・状態などによる絞り込み
- DOI、PMID、正規化タイトル／タイトル類似度による重複候補確認
- タグの作成・名称変更・削除と、文献への付与・解除
- 文献の使用履歴の登録・編集・削除
- 全文献または直前の検索結果のCSV出力
- SQLiteデータベースのバックアップ

重複候補が見つかっても、自動統合や自動削除は行いません。登録を続けるか中止するかは利用者が判断します。著者名と出版年だけでは、Phase 1の重複候補として自動判定しません。

## Phase 1でしないこと

- PubMed API、Crossref APIとの連携
- DOIなどからの書誌情報の自動取得
- AIによる要約の自動生成
- PDF本文の解析
- 文献の手動統合、note記事の自動生成
- GUI、Web UI
- クラウド同期、複数ユーザー対応

## 必要環境と起動方法

macOSとPython 3を前提とします。外部Python packageは不要で、Python標準ライブラリだけを使用します。

リポジトリルートで次を実行してください。

```bash
python3 -m src
```

初回起動時に必要なローカル保存先とSQLiteデータベースが作成されます。

## 保存先

- データベース: `data/pt_research_library.sqlite3`
- CSV: `exports/`
- SQLiteバックアップ: `backups/`

これらはリポジトリルートを基準とするローカル生成物です。実データ、生成CSV、バックアップはGitHubの管理対象にしません。

## メインメニュー

```text
1. 文献一覧
2. 文献検索
3. 文献登録
4. 文献編集
5. 文献削除
6. タグ管理
7. 使用履歴管理
8. 文献詳細
9. CSV出力
10. SQLiteバックアップ
0. 終了
```

文献削除では、タグ関連付け数と使用履歴数を表示し、2段階の確認を行います。文献を削除すると関連付けと使用履歴は削除されますが、タグ本体と`pdf_path`が示す外部ファイルは削除されません。

## AI要約

Phase 1ではAI要約を自動生成しません。`ai_summary`は利用者が手動で登録・編集し、`ai_summary_status`で確認状態を管理します。AI生成内容は、利用者が確認するまでは未確認として扱ってください。

## CSV出力

CSVはExcelでも扱いやすいUTF-8 BOM付きで出力します。全文献または直前の検索結果を選択でき、タグはセミコロン区切りの`tags`列に含まれます。使用履歴は文献一覧CSVには含まれません。

## SQLiteバックアップ

バックアップはSQLiteのバックアップ機能を使用し、`backups/`へ保存します。既存バックアップを上書きせず、作成後に整合性を確認します。未Commitのトランザクション中は実行できません。Phase 1 CLIに自動復元機能はありません。

## テスト

リポジトリルートで次を実行します。テストは一時ディレクトリと合成データだけを使用します。

```bash
python3 -m unittest discover -s tests -v
```

## データ安全性

- productionデータベース、生成CSV、バックアップをGitHubへcommitしないでください。
- 文献PDF、超音波画像・動画、参加者情報、分析データ、APIキーや認証情報をcommitしないでください。
- 実際の研究データをテストへ入れないでください。
- データベースをバックアップしてから、削除操作を行うことを推奨します。
